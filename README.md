# Week 07 – Enterprise Network Security & Monitoring

This repository contains my Week 07 Network Administration internship work completed using GNS3 and Cisco IOS.

## Topics Covered

- IPsec VPN
- IKE Phase 1 & IPsec Phase 2
- Pre-shared Key Authentication
- Transform Set & Crypto Map
- SSH Version 2
- Telnet Disabled
- AAA & Local User Authentication
- Password Encryption
- MOTD Banner
- Secure VTY Configuration
- OSPF Authentication
- Passive Interface
- Prefix-list Filtering
- NTP Configuration
- Syslog / Router Logging
- SNMPv3
- Basic Router Hardening
- Ping & Traceroute Verification
- VPN Verification
- ACL Verification

## Tools Used

- GNS3
- Cisco IOS
- PuTTY

## Verification

The network was verified using ping, traceroute, IPsec/IKE status, ACL verification, and router logging commands.

## Note

Zone-Based Firewall could not be configured on the available C7200 IOS image because the required `zone security` command was not supported by the IOS version used.
